# Plan: hiring-code-python — Gear Garage Flask App

## Context

Build a Python version of the "Gear Garage" hiring/interview starter project that lives at `~/projects/hiring-code-ruby`. The Ruby version is a Rails 8.1 app that fetches gear categories and listings from the Reverb.com API, demonstrating MVC patterns, external HTTP integration, and testing. The Python version should be structurally equivalent so candidates with a Python background get the same exercise.

Requirements: modern Python stack (2025/2026), GitHub Codespaces support, same features (categories search, listings grid, navigation), same docs/features/ interview spec structure.

### 3. `app/__init__.py` — App Factory

```python
from flask import Flask
from dotenv import load_dotenv

load_dotenv()

def create_app():
    app = Flask(__name__)
    from app.routes.categories import categories_bp
    from app.routes.listings import listings_bp
    app.register_blueprint(categories_bp)
    app.register_blueprint(listings_bp)
    return app
```

### 4. `app/clients/reverb.py` — HTTP Client

Mirror of `lib/clients/reverb.rb`. Module-level functions (Python idiom for stateless service).

```python
import os
import httpx

HEADERS = {"Accept": "application/json", "Accept-Version": "3.0"}
CATEGORIES_FLAT_PATH = "categories/flat"
LISTINGS_PATH = "listings"

def _get(path, params=None):
    host = os.environ["REVERB_HOST"]
    response = httpx.get(f"{host}/api/{path}", params=params or {}, headers=HEADERS)
    response.raise_for_status()
    return response.json()

def categories():
    return _get(CATEGORIES_FLAT_PATH)["categories"]

def listings(per_page=10):
    return _get(LISTINGS_PATH, {"per_page": per_page})["listings"]
```

### 5. `app/routes/categories.py`

```python
from flask import Blueprint, render_template, request
from app.clients import reverb

categories_bp = Blueprint("categories", __name__)

@categories_bp.route("/")
@categories_bp.route("/categories")
def index():
    search_term = request.args.get("search", "").strip()
    matched_categories = []
    if search_term:
        matched_categories = [
            c for c in reverb.categories()
            if search_term.lower() in (c.get("full_name") or "").lower()
        ]
    return render_template("categories/index.html", categories=matched_categories, search_term=search_term)
```

### 6. `app/routes/listings.py`

```python
from flask import Blueprint, render_template
from app.clients import reverb

listings_bp = Blueprint("listings", __name__)

@listings_bp.route("/listings")
def index():
    return render_template("listings/index.html", listings=reverb.listings())
```

### 7. Templates

**`app/templates/layout.html`** — base layout with Pico CSS v2 CDN, HTMX CDN (available for optional enhancement), `{% include "partials/navigation.html" %}`, and `{% block content %}`.

**`app/templates/partials/navigation.html`** — Pico CSS `<nav>` with two `<ul>` tags (logo-left, links-right). Uses `url_for('categories.index')` and `url_for('listings.index')`. Same SVG logo as Ruby version.

**`app/templates/categories/index.html`** — `{% extends "layout.html" %}`. Search form (GET, `name="search"`, `value="{{ search_term }}"`). Results shown only when `search_term` is set. Uses `{% for category in categories %}` with `<article class="category-card">`. Shows "No categories found" empty state when no matches.

**`app/templates/listings/index.html`** — `{% extends "layout.html" %}`. Uses Jinja2 `{% set photo_url = ... %}` to safely navigate nested dict for thumbnail. `<div class="listings-grid">` with `<article class="listing-card">` cards.

### 9. `tests/conftest.py`

```python
import pytest
from app import create_app

@pytest.fixture()
def client():
    app = create_app()
    app.config["TESTING"] = True
    with app.test_client() as client:
        yield client
```

No pytest-flask. Plain pytest fixtures using Flask's built-in `app.test_client()` context manager. The `client` fixture is used directly in all tests.

### 10. `tests/test_listings.py`

Mirrors `spec/requests/listings_spec.rb`. Use `unittest.mock.patch("app.routes.listings.reverb.listings", return_value=[...])`. Assert HTTP 200, photo `src`, and title in `response.data`.

### 11. `tests/test_categories.py`

Mirrors `spec/requests/categories_spec.rb`. Patch target: `"app.routes.categories.reverb.categories"`. Cover: empty search shows form, matching search shows cards, case-insensitive match, no-match shows empty state, root route renders categories view.

### 12. `tests/clients/test_reverb.py`

Mirrors `spec/lib/clients/reverb_spec.rb`. Use `unittest.mock.patch("httpx.get")` with a mock that returns a `MagicMock` with `.json()` returning fixture data and `.raise_for_status()` as a no-op. Also use `monkeypatch.setenv("REVERB_HOST", "https://api.reverb.test")` to avoid needing the real API. Test: categories returns list, listings returns list, per_page param is forwarded.
